Place a SoundFont file here named exactly:

    soundfont.sf2

Recommended free options:
  - TimGM6mb (~5.7 MB, MIT)
  - GeneralUser GS (~30 MB)

If no soundfont.sf2 is present, the mod falls back to:
  1. Zomboid/midi/soundfont.sf2 (user override)
  2. JVM built-in EmergencyGMSoundbank (very basic, but always available)
